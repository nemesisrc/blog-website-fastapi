## 📖 Overview
A robust, full-featured blog web application and API built with **FastAPI**. This project features comprehensive user authentication, post creation, profile management, and a highly responsive front-end. 

Developed by Rajdeep Chakraborty, this project demonstrates a scalable backend architecture foundation, applying professional-grade standards suitable for personal blogging, extending into a larger content management system, or serving as a headless CMS API.

## ✨ Features
- **User Authentication:** Secure user registration, login, session management, and password hashing (via OAuth2/JWT).
- **CRUD Operations:** Complete Create, Read, Update, and Delete functionality for blog posts.
- **User Profiles:** Individual user profiles with dynamic avatar management and personalized post histories.
- **Pagination:** Efficient querying and rendering to navigate through multiple blog posts smoothly.
- **Interactive API Documentation:** Auto-generated, interactive Swagger UI and ReDoc endpoints out of the box.

## 🛠️ Tech Stack
- **Backend Framework:** FastAPI (Python 3.x)
- **Database ORM:** SQLAlchemy
- **Database:** SQLite *(Can be easily migrated to PostgreSQL)*
- **Templating:** Jinja2
- **Styling/UI:** Bootstrap / Custom CSS
